Каждая тема добавляет к ней один участок. Ниже перечислено, что после
каждой темы есть у вас в проекте.

```text

                     │
                     └─▶ форма ─▶ Apps Script ─▶ Google Таблица leads ─▶ leads_clean
                                                         │
Instagram ─▶ ManyChat ─▶ guide.html ─────────────────────┤
                                                         └─▶ DataLens: общий дашборд
```

## Темы впереди

Дальнейшие занятия взяты из календарно-тематического плана дисциплины
(КТП). Номер занятия по КТП не совпадает с номером темы в таблице выше.
Занятия КТП 1–7 и 20 уже пройдены в темах 2–10.2, но с другими
сервисами. Google Tag подключали напрямую, без Google Tag Manager.
Данные очищали формулами Google Таблиц вместо Power Query. Дашборд
собирали в DataLens вместо Looker Studio.

Оставшиеся занятия посвящены передаче заявки между сервисами. В таблице
встречаются четыре новых слова:

- **API** — набор адресов, через которые одна программа запрашивает
  данные у другой или передаёт их ей;
- **webhook** — адрес, на который сервис сам отправляет данные, когда
  что-то произошло, например пришла новая заявка;
- **n8n** — сервис, в котором автоматизацию собирают из блоков-узлов:
  узел «принять заявку», узел «записать в таблицу», узел «отправить
  сообщение»; такая цепочка называется **workflow**;
- **CRM** — система учёта клиентов: каждая заявка в ней становится
  карточкой со статусом.
